# Comandos git

## 

## Comando - Palavra-chave para memorizar



git init Inicializar
git clone - clonar
git status - verificar
git add - preparar
git commit - Registrar
git log - consultar histórico
git diff - comparar alterações
git push - enviar
git pull - buscar e integrar
git fetch - buscar sem integrar
git branch - Listar ou criar branches
git switch - trocar de branch
git merge - integrar branches
git restore - restaurar arquivos
git revert - desfazer por meio de um novo commit
git remote -v - consultar repositórios remotos
